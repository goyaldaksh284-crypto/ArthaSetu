# ArthaSetu - Smart Financial Companion for Gig Workers

ArthaSetu is an AI-powered financial management system designed specifically for India's gig economy workforce (delivery partners, rideshare drivers, and freelancers).

## 🎯 Key Capabilities

- **Instant Demo Access**: 1-click test login as Rahul Sharma (`9876543210` / `password123`) or register any mobile number.
- **Resilient Hybrid Storage**: Seamlessly operates with local browser persistence (`localStorage`) and automatically syncs to Supabase when live credentials are provided.
- **Smart Transactions Tracking**: Manual, receipt photo OCR, and voice entry with intelligent offline fallbacks.
- **Budgeting & Cashflow Protection**: Dynamic Feast / Famine cashflow adaptation and category spending limits.
- **Savings & Micro-Investments**: Goal tracking (Emergency Fund, EV transition), daily micro-SIP recommendations.
- **Tax Calculation**: Automated New Tax Regime FY24-25 / FY25-26 slabs and Section 87A rebate calculations.
- **Risk Assessment**: Financial health scoring, emergency buffer runways, and DTI ratios.
- **Government Schemes**: PM-SYM pension, PMSBY accidental insurance, PMJJBY life cover, and Ayushman Bharat health card guidance.
